# editable-prompts-template-items: visual proof of the "Show available
# template items" change to the prompt-override manager's editor.
#
# The template editor now lists the {{token}} placeholders the selected
# prompt declares (PromptSpec::placeholders) on an "Available template
# items:" line above the edit box, so a user knows which tokens they can
# use before editing. This walks: manager list -> editor for a
# many-placeholder prompt (review.batch, 5 tokens, wrapped list) ->
# editor for a single-placeholder prompt (review.changeset_overview) -> the
# updated help panel.
#
#   scripts/dev/screenshot/aiw-capture.sh \
#     --scenario     scripts/dev/screenshot/scenarios/editable-prompts-template-items.txt \
#     --seed         scripts/dev/screenshot/scenarios/editable-prompts-seed-project.json \
#     --seed-feature scripts/dev/screenshot/scenarios/editable-prompts-seed-feature.json \
#     --geometry 150x44

# Let the seed's harness-config toast clear first.
wait:1600
note:The dashboard with a seeded project and feature; the feature must be selected so the editor and its save flow have all three scopes available.
key:j
wait:300
shot:feature-selected

# `E` opens the prompt-override manager.
key:E
wait:500
note:The prompt-override manager lists every headless prompt AIW sends; all start on the built-in default.
shot:manager-list

# Down to "Batched review: diff slice" (row 6 of the list: five `j` from the top).
key:j
wait:120
key:j
wait:120
key:j
wait:120
key:j
wait:120
key:j
wait:150
note:The "Batched review: diff slice" row is selected -- a prompt that takes a wrapped list of runtime context.
shot:review-batch-row

# `Enter` opens the editor pre-filled with the effective template.
key:Enter
wait:500
note:The editor now shows an "Available template items:" line listing all five {{token}} placeholders review.batch accepts -- skill_directive, recurring_findings, file_list, annotated_diff and finding_heading_prefix -- wrapped across lines.
shot:editor-many-items

# Back to the list, then up to a single-placeholder prompt.

wait:120
